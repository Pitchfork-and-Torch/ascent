LEO path foresight for usable session bandwidth and session continuity. next_capacity is predicted bottleneck bits/s as seen by the sender, not RF PHY.     Resilience
    
    
    Usable session bandwidth, not RF slogans.
    
    
    Dual-mode plan so a terminal stays useful when your fiber dies. Starlink is last-mile IP. ASCENT is the wire. SkyPulse PATHHINT is foresight for CCA/apps (growth freeze, seed predicted sender bottleneck). Grok is cloud compute. When the API is gone, edge models take over. ASCENT does not make Starlink faster at RF. Not a bare bandwidth upgrade.
    
    
    
      
    
        
    Modes
    
        
    CLOUD  - api.x.ai reachable, path stable
EDGE   - local OpenAI-compatible model
QUEUE  - obstruction / RTT flap / store-forward
DEAD   - honest fail (no power / no model)

SkyPulse PATHHINT: bottleneck_hint + freeze_until (usable session bandwidth, not RF)
ASCENT-E-LEO: light CRC or short RS, no full P9 on interactive IP
ASCENT-D: full RS(255,223) P9 for spool / deep-space / high-BER only

    FAQ
    
    
    Short answers you can cite.
    
    
    
      
    
        What is ASCENT?
        
    ASCENT (ASCII Successor with Compatible Encoding of Named Text) is a wire encoding and control grammar that keeps classic 7-bit ASCII bit-identical on bytes 0-127 forever, then adds agent frames, multimodal refs, quantum-safe control, and a deep-space ECC profile.
    
      
    
      
    
        Does ASCENT break existing ASCII files?
        
    No. Pure classic ASCII files are valid ASCENT-7. Any byte less than 0x80 is classic ASCII, width 1, forever. Greppers, shebangs, and SMTP 7-bit paths remain correct on that subset.
    
      
    
      
    
        What is Wire Lab 3.0 Crystal Wire?
        
    The interactive public face of ASCENT. Dual editors, SkyPulse PATHHINT, agent and multimodal composers, ASCENT-D erase-on-fail, AEGIR sketch, eleven-plane explorer, command palette, mission HUD, and shareable hex URLs.
    
      
    
      
    
        Does SkyPulse make Starlink faster at RF?
        
    No. PATHHINT is a fail-closed usable-session-bandwidth / CCA hint. It does not raise physical RF Mbps. ASCENT-E-LEO uses light integrity on interactive IP. ASCENT-D is for spool and deep space.
